# **App Name**: BGMI Config Pro

## Core Features:

- Config Generation: AI-powered tool to generate optimized BGMI config files based on user hardware specifications, game settings preferences, and desired features (aim assist, aimbot, no recoil, FPS, enemy location, bullet tracker, auto aim, FPS unlock).
- Feature selection: Allow users to choose desired features.
- Configuration Download: Enable config downloads, plus in-app guidance on config installation into the BGMI folder.
- Monetization: Display in-app advertisements (ad banner and video interstitial)

## Style Guidelines:

- Primary color: A vibrant blue (#29ABE2) to convey a sense of technology, trust, and optimization.
- Background color: Dark gray (#333333) to provide a high-contrast backdrop for game-related content.
- Accent color: Bright green (#90EE90) for highlights, selections, and calls to action to represent enhancement and performance.
- Headline font: 'Space Grotesk' (sans-serif) for headlines; Body font: 'Inter' (sans-serif) for body; to combine a tech-oriented style with good legibility.
- Use clear, sharp icons with a neon outline to highlight configurations and settings.
- High contrast layout to improve readability on mobile devices.
- Subtle animations on configuration generation.
